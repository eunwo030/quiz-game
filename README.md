# 🎯 나만의 파이썬 콘솔 퀴즈 게임 (quiz-game)

본 프로젝트는 파이썬 기본 문법, 객체 지향 프로그래밍(OOP), 파일 입출력(JSON), 그리고 Git/GitHub 워크플로우를 학습하고 실습하기 위해 제작된 콘솔 기반 퀴즈 게임 프로그램입니다.

---

## 📌 1. 퀴즈 주제 및 선정 이유
- **주제:** 배은우 맞춤형 인물 퀴즈 및 파이썬 기초 퀴즈
- **선정 이유:** 프로그래밍의 기초 개념(자료형, 조건문, 함수 등)과 사용자 지정 데이터 간의 흐름을 직관적으로 확인하고 재미있게 테스트하기 위해 선정했습니다.

---

## 🚀 2. 실행 방법

1. 저장소를 클론(Clone)합니다.
git clone [https://github.com/eunwo030/quiz-game.git](https://github.com/eunwo030/quiz-game.git)
cd quiz-game

2. 파이썬 프로그램을 실행합니다. (Python 3.10 이상 권장)
python main.py

---

## 🛠️ 3. 주요 기능 목록

- 🎯 1. 퀴즈 풀기: 저장된 퀴즈가 순서대로 출제되며 정답 입력 시 점수를 집계합니다. 최고 점수 달성 시 갱신 및 파일 저장됩니다.
- 📌 2. 퀴즈 추가: 문제, 4개 선택지, 정답 번호를 직접 받아 새로운 퀴즈를 등록합니다.
- 📋 3. 퀴즈 목록: 현재 등록되어 있는 퀴즈 문제들의 목록을 한눈에 확인할 수 있습니다.
- 🏆 4. 최고 점수 확인: 역대 퀴즈 풀기에서 달성한 최고 점수를 보여줍니다.
- ⚠️ 5. 예외 처리: 
  - 잘못된 숫자/문자/빈 칸 입력 시 안내 메시지 출력 후 재입력 유도
  - Ctrl+C 또는 입력 종료 시 비정상 종료 방지 및 안전한 데이터 저장
  - 데이터 파일 손상/부재 시 기본 데이터 복구 로직 포함

---

## 📁 4. 프로젝트 파일 구조

- main.py : 퀴즈 게임 메인 실행 파일 (Quiz, QuizGame 클래스)
- state.json : 퀴즈 데이터 및 최고 점수가 저장되는 JSON 파일
- .gitignore : Git 추적 제외 파일 목록
- README.md : 프로젝트 설명 문서

---

## 📂 5. 데이터 파일 설명 (state.json)

- 경로: 프로젝트 루트 디렉터리 ./state.json
- 역할: 프로그램 종료 후에도 추가한 퀴즈와 최고 점수가 유지되도록 UTF-8 인코딩으로 저장
- 데이터 스키마 예시:
{
    "quizzes": [
        {
            "question": "배은우가 사는 지역은?",
            "choices": ["서울", "부산", "대전", "광주"],
            "answer": 3
        }
    ],
    "best_score": 5
}
